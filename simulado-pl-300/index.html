Questão 1 de 12 · Gerenciar e proteger o Power BI

Um relatório com dados salariais deve ser classificado como Confidencial, e a classificação deve acompanhar o arquivo quando exportado para Excel. O que aplicar?

Resposta: A) Rótulo de confidencialidade

Por quê: O Power BI aplica rótulos de confidencialidade do Microsoft Purview a modelos, relatórios e exportações para Excel, PowerPoint e PDF.

Dica de prova: Classificação que acompanha a exportação: rótulo de confidencialidade.

Referência: Rótulos de confidencialidade no Power BI

Questão 2 de 12 · Modelar os dados

As tabelas Cliente e ClienteDetalhe têm a mesma chave, uma linha por cliente em cada uma. Qual é a abordagem recomendada no modelo?

Resposta: B) Mesclar as duas em uma única dimensão

Por quê: Relacionamentos um-para-um geralmente indicam que as tabelas podem ser mescladas no Power Query, reduzindo complexidade.

Dica de prova: Um-para-um: considere juntar as tabelas.

Referência: Relacionamentos um-para-um

Questão 3 de 12 · Preparar os dados

Uma coluna de valores monetários com até quatro casas decimais deve evitar erros de arredondamento de ponto flutuante. Qual tipo de dado usar no Power Query?

Resposta: B) Decimal fixo

Por quê: Escolher tipos corretos cedo no Power Query melhora a qualidade e o tamanho do modelo. Decimal fixo é indicado para valores financeiros.

Dica de prova: Dinheiro com precisão: decimal fixo.

Referência: Tipos de dados no Power BI Desktop

Questão 4 de 12 · Visualizar e analisar os dados

Em uma matriz de vendas por região e mês, as regiões sem vendas em algum mês não aparecem, e o gestor quer vê-las com células vazias. Qual opção ativar?

Resposta: C) Opção Mostrar itens sem dados

Por quê: Por padrão, visuais ocultam combinações sem dados. A opção Mostrar itens sem dados é configurada no campo do visual.

Dica de prova: Exibir linhas sem valor: mostrar itens sem dados.

Referência: Mostrar itens sem dados

Questão 5 de 12 · Gerenciar e proteger o Power BI

Um único analista precisa atualizar no serviço um modelo que usa uma planilha do seu computador, sem envolver a TI. Qual opção de gateway atende a esse uso individual?

Resposta: C) Gateway de dados local no modo pessoal

Por quê: O gateway pessoal é simples para uso individual; para compartilhar fontes e usar DirectQuery, use o gateway padrão.

Dica de prova: Uso individual com arquivo local: gateway pessoal.

Referência: Gateway no modo pessoal

Questão 6 de 12 · Modelar os dados

Um gráfico de vendas por categoria mostra uma barra '(Em branco)'. Qual é a causa mais comum?

Resposta: C) Vendas com código de produto sem correspondência na dimensão

Por quê: O Power BI adiciona uma linha em branco virtual na dimensão quando há chaves no fato sem correspondência, sinalizando problemas de integridade.

Dica de prova: (Em branco) no eixo: chave do fato sem par na dimensão.

Referência: Relacionamentos de modelo

Questão 7 de 12 · Preparar os dados

No Editor do Power Query, a criação de perfil mostra estatísticas diferentes das esperadas para uma tabela grande. Qual é a causa mais provável?

Resposta: D) O perfil usa as primeiras 1.000 linhas por padrão

Por quê: Na barra de status do Power Query, é possível trocar a criação de perfil para 'com base no conjunto de dados inteiro'.

Dica de prova: Perfil estranho em tabela grande: amostra de 1.000 linhas.

Referência: Ferramentas de criação de perfil de dados

A empresa quer que todos os relatórios usem as mesmas cores, fontes e estilos de visuais, sem configurar cada relatório manualmente. Qual recurso atende?

Resposta: A) Tema de relatório em JSON

Por quê: Temas personalizados padronizam a identidade visual e podem ser salvos e distribuídos como arquivos JSON.

Questão 9 de 12 · Gerenciar e proteger o Power BI

Qual é a menor função de workspace que permite publicar e atualizar o aplicativo do workspace?

Resposta: A) Função Membro

Por quê: Administradores e Membros publicam apps. Colaboradores podem atualizar o app se houver a configuração específica do workspace.

Dica de prova: Publicar o app: a partir de Membro.

Referência: Funções nos workspaces

Questão 10 de 12 · Modelar os dados

Por que a filtragem cruzada bidirecional deve ser usada com cautela em um modelo com várias tabelas de fatos?

Resposta: A) Pode criar ambiguidade e deixar consultas lentas

Por quê: Prefira filtros de direção única, da dimensão para o fato. Quando necessário, use CROSSFILTER em medidas específicas.

Dica de prova: Bidirecional com moderação: ambiguidade e lentidão.

Referência: Filtragem bidirecional

Questão 11 de 12 · Preparar os dados

Após o time de TI renomear a coluna Valor para ValorTotal no banco, a atualização falha com o erro 'A coluna Valor não foi encontrada'. Como corrigir no Power Query?

Resposta: B) Ajustar a etapa que referencia o nome antigo

Por quê: Etapas do Power Query referenciam colunas pelo nome. Mudanças na fonte exigem revisar etapas como tipos alterados e colunas removidas.

Dica de prova: Coluna renomeada na fonte: ajustar a etapa.

Referência: Lidar com erros no Power Query

Para usuários com daltonismo, um gráfico de linhas com várias séries fica difícil de ler. Qual ajuste melhora a acessibilidade?

Resposta: A) Usar marcadores com formas diferentes nas séries

Por quê: Não depender apenas de cor, usar contraste adequado e marcadores distintos são práticas de relatórios acessíveis.

Dica de prova: Daltonismo: não dependa só da cor.

Referência: Relatórios acessíveis
