Questão 1 · Implementar soluções de IA generativa e agênticas

Um banco está ajustando o índice de busca do seu app de RAG sobre normas internas. A equipe de compliance já rotulou, para 300 perguntas de teste, quais documentos são relevantes e com que grau de relevância. O objetivo é comparar configurações de busca com métricas como NDCG e fidelidade. Qual avaliador você deve usar?

  1. Document Retrieval
  2. Relevance
  3. Retrieval
  4. Response Completeness
Ver resposta comentada

Resposta: A) Document Retrieval

Resposta correta: Document Retrieval

Por quê: Ao avaliar RAG, separe a etapa de recuperação (Document Retrieval com rótulos ou Retrieval sem rótulos) da etapa de geração (Groundedness, Relevance e Response Completeness).

Dica de prova: Tem rótulos de relevância (qrels) e quer NDCG? Document Retrieval.

Referência: Avaliadores de RAG no Microsoft Foundry

Questão 2 · Implementar soluções de análise de texto

Um órgão de transparência pública precisa divulgar contratos em PDF e DOCX com nomes, CPFs e endereços ocultados, mantendo a formatação original dos arquivos e obtendo também metadados em JSON das ocultações. Qual recurso do Azure Language atende ao requisito?

  1. PII de conversa, tratando cada cláusula como um turno de diálogo
  2. NER pré-configurado, removendo as entidades encontradas no arquivo
  3. PII baseada em documentos, com processamento assíncrono dos arquivos nativos
  4. PII de texto, enviando o conteúdo extraído de cada página do contrato
Ver resposta comentada

Resposta: C) PII baseada em documentos, com processamento assíncrono dos arquivos nativos

Resposta correta: PII baseada em documentos, com processamento assíncrono dos arquivos nativos

Por quê: Escolha o tipo de PII pelo formato da entrada: Text PII para strings (síncrono), Conversation PII para diálogos e transcrições e Document PII para arquivos nativos em pipelines baseados em armazenamento.

Dica de prova: Ocultar PII mantendo o PDF ou DOCX = Document PII.

Referência: Detecção de PII no Azure Language

Resposta correta: Definir tableFormat como markdown no config do analisador

Questão 4 · Implementar soluções de visão computacional

Uma editora de revistas gera ilustrações com um modelo gpt-image no Foundry e precisa cumprir uma política interna de transparência: as imagens devem carregar sinais verificáveis de que foram geradas por IA, e a equipe de checagem precisa verificar esses sinais em lote antes da publicação. O que você deve usar?

  1. Uma marca d'água visível inserida pela API de edição de imagens com máscara
  2. Um custom category (rapid) do Content Safety alimentado com imagens geradas por IA
  3. Content Credentials (C2PA) e marcas d'água invisíveis, verificadas pela Content Provenance Detection API
  4. Metadados EXIF gravados pelo aplicativo e lidos pela análise de imagem do Azure Vision
Ver resposta comentada

Resposta: C) Content Credentials (C2PA) e marcas d'água invisíveis, verificadas pela Content Provenance Detection API

Resposta correta: Content Credentials (C2PA) e marcas d'água invisíveis, verificadas pela Content Provenance Detection API

Por quê: Item do guia 'Impor regras de política visual, como aplicar marcas d'água ...': a procedência de conteúdo combina C2PA e marcas d'água invisíveis; ela informa a origem, mas não atesta veracidade nem autoria.

Dica de prova: Provar que a imagem é de IA = C2PA + marca d'água invisível, verificadas pela Provenance Detection API.

Referência: Procedência de conteúdo para modelos do Foundry

Questão 5 · Planejar e gerenciar uma solução de IA do Azure

Um agente de uma seguradora lê e-mails de prestadores de serviço por meio de uma ferramenta MCP antes de atualizar sinistros. A equipe de segurança teme instruções ocultas nesses e-mails tentando manipular o agente. Ao configurar o guardrail do agente com o controle de ataques indiretos, em qual ponto de intervenção esse conteúdo vindo da ferramenta deve ser verificado?

  1. Resposta da ferramenta (tool response), que analisa o conteúdo devolvido ao agente
  2. Chamada da ferramenta (tool call), que analisa os dados enviados para a ferramenta
  3. Entrada do usuário (user input), que analisa o prompt digitado pelo corretor
  4. Saída (output), que analisa a resposta final entregue ao usuário do agente
Ver resposta comentada

Resposta: A) Resposta da ferramenta (tool response), que analisa o conteúdo devolvido ao agente

Resposta correta: Resposta da ferramenta (tool response), que analisa o conteúdo devolvido ao agente

Por quê: Guardrails têm quatro pontos de intervenção: entrada do usuário, chamada de ferramenta e resposta de ferramenta (ambas em preview, só para agentes) e saída. O Prompt Shields para ataques a documentos procura instruções ocultas em conteúdo de terceiros e atua na entrada do usuário e na resposta da ferramenta.

Dica de prova: Instrução escondida no que a ferramenta devolve = controle no tool response.

Referência: Visão geral de guardrails e controles no Foundry

Questão 6 · Implementar soluções de IA generativa e agênticas

Um aplicativo de uma fintech usa o Foundry SDK com o endpoint do projeto para conversar com modelos e agentes. Agora a equipe precisa gerar embeddings dos documentos de política de crédito para alimentar um índice vetorial, mas as chamadas de embeddings feitas pelo endpoint do projeto não funcionam. O que você deve fazer?

  1. Usar o AIProjectClient com a connection string de um projeto baseado em hub
  2. Usar o endpoint de Foundry Tools com o SDK da Azure Language
  3. Usar a Responses API do agente com o code interpreter habilitado
  4. Usar o OpenAI SDK com o endpoint do recurso terminado em openai/v1
Ver resposta comentada

Resposta: D) Usar o OpenAI SDK com o endpoint do recurso terminado em openai/v1

Resposta correta: Usar o OpenAI SDK com o endpoint do recurso terminado em openai/v1

Por quê: Ao integrar fluxos generativos com SDKs do Foundry: o cliente do projeto atende agentes, Responses API, avaliações e conexões; para embeddings, use o OpenAI SDK no endpoint /openai/v1 do recurso.

Dica de prova: Embeddings não passam pelo endpoint do projeto: use o OpenAI SDK em /openai/v1.

Referência: SDKs e endpoints do Microsoft Foundry

Questão 7 · Implementar soluções de análise de texto

Uma startup de software para call centers quer que um modelo analise diretamente a gravação de uma ligação, e não só a transcrição, para avaliar hesitação, interrupções e tom do cliente, devolvendo um parecer em texto ao supervisor. Qual abordagem você deve usar?

  1. Enviar o áudio a um modelo com entrada de áudio na API Chat Completions e pedir saída em texto
  2. Gerar legendas com a transcrição rápida e aplicar uma phrase list de termos de emoção e hesitação
  3. Transcrever em lote e enviar só o texto à análise de sentimento do Azure Language
  4. Usar text to speech com SSML para reproduzir a ligação e medir a prosódia gerada
Ver resposta comentada

Resposta: A) Enviar o áudio a um modelo com entrada de áudio na API Chat Completions e pedir saída em texto

Resposta correta: Enviar o áudio a um modelo com entrada de áudio na API Chat Completions e pedir saída em texto

Por quê: Item do guia 'Habilitar o raciocínio multimodal de entradas de áudio': os modelos de áudio ampliam a Chat Completions com entradas e saídas de áudio, inclusive para análise de áudio.

Dica de prova: Raciocinar sobre a voz, não só sobre o texto = modelo com entrada de áudio.

Referência: Entrada e geração de áudio no Azure OpenAI

Questão 8 · Implementar soluções de extração de informações

Uma plataforma de notícias habilitou o ranqueador semântico no Azure AI Search, mas os resultados reclassificados ignoram informações importantes do corpo das matérias, que são longas. Na configuração semântica, o campo de tags foi definido como primeiro campo de conteúdo e o corpo da matéria como último. O que você deve ajustar?

  1. Aumentar o top da consulta para mais de 50 para que mais resultados sejam reclassificados pelo modelo
  2. Converter o corpo da matéria em campo vetorial para incluí-lo na reclassificação
  3. Reordenar os campos por prioridade, pondo o corpo antes, pois os de baixa prioridade são truncados
  4. Mover o corpo da matéria para o campo de título, que aceita textos longos sem limite
Ver resposta comentada

Resposta: C) Reordenar os campos por prioridade, pondo o corpo antes, pois os de baixa prioridade são truncados

Resposta correta: Reordenar os campos por prioridade, pondo o corpo antes, pois os de baixa prioridade são truncados

Por quê: Item do guia 'Configurar pesquisa semântica, pesquisa híbrida e pesquisa de vetor para fundamentação': a configuração semântica define um título e campos de conteúdo e de palavras-chave em ordem de prioridade, e cada documento contribui com até 2.048 tokens resumidos.

Dica de prova: Ranqueador semântico ignorando texto? Revise a ordem dos campos na configuração semântica.

Referência: Ranqueamento semântico no Azure AI Search

Questão 9 · Implementar soluções de visão computacional

Uma startup de jogos usa um modelo GPT-image-1 para gerar ícones de itens que serão sobrepostos a fundos diferentes dentro do aplicativo. Os ícones precisam ter fundo transparente, e a equipe também quer qualidade alta. Quais parâmetros você deve definir na chamada de geração?

  1. background como auto, output_format como jpeg e quality como low
  2. response_format como url, size como 1024x1024 e quality como high
  3. background como transparent, output_format como png e quality como high
  4. background como transparent, output_format como jpeg e output_compression como 100

Resposta: C) background como transparent, output_format como png e quality como high

Resposta correta: background como transparent, output_format como png e quality como high

Por quê: Item do guia 'Selecionar e aplicar os controles de geração e edição apropriados fornecidos pela plataforma': os modelos GPT-image aceitam quality, size, n, output_format, output_compression e background, com dependências entre eles.

Questão 10 · Planejar e gerenciar uma solução de IA do Azure

Uma seguradora vai criar três agentes (sinistros, subscrição e ouvidoria) que precisam responder com base nas mesmas apólices e normas internas, armazenadas no SharePoint e no Azure Blob Storage. As respostas devem trazer citações e respeitar as permissões de cada usuário sobre os documentos. Qual recurso você deve usar para fornecer esse conhecimento aos agentes?

  1. A ferramenta Code Interpreter com os PDFs das apólices anexados ao contêiner de cada agente
  2. A ferramenta de pesquisa de arquivos com os documentos enviados em cada conversa pelo usuário
  3. Um repositório de memória do Foundry Agent Service com memória de perfil de usuário ativada
  4. Uma base de conhecimento do Foundry IQ com fontes de conhecimento compartilhadas pelos três agentes
Ver resposta comentada

Resposta: D) Uma base de conhecimento do Foundry IQ com fontes de conhecimento compartilhadas pelos três agentes

Resposta correta: Uma base de conhecimento do Foundry IQ com fontes de conhecimento compartilhadas pelos três agentes

Por quê: A documentação orienta: memória para contexto específico do usuário, base de conhecimento do Foundry IQ para conteúdo organizacional curado e pesquisa de arquivos para documentos enviados durante a interação. O Foundry IQ usa a recuperação agêntica do Azure AI Search, sincroniza ACLs e pode ser compartilhado por vários agentes.

Dica de prova: Conteúdo corporativo curado + vários agentes + permissões = Foundry IQ.

Resposta correta: Avaliação contínua com uma regra de avaliação e limite de execuções por hora

Questão 12 · Implementar soluções de análise de texto

A operadora Alô Brasil quer substituir a URA tradicional por um agente de voz em tempo real com baixa latência de fala para fala, supressão de ruído para clientes que ligam da rua, detecção de fim de turno que tolere pausas naturais e uma voz personalizada da marca, sem orquestrar manualmente reconhecimento, modelo e síntese. O que você deve usar?

  1. A tradução de fala com o Live Interpreter configurado para o mesmo idioma
  2. A transcrição em lote do Azure Speech, seguida de um modelo GPT e de síntese de fala em lote
  3. A Voice Live API, com supressão de ruído, detecção de fim de turno e voz personalizada
  4. A transcrição rápida com diarização, seguida de text to speech com SSML
Ver resposta comentada

Resposta: C) A Voice Live API, com supressão de ruído, detecção de fim de turno e voz personalizada

Resposta correta: A Voice Live API, com supressão de ruído, detecção de fim de turno e voz personalizada

Por quê: Item do guia 'Implementar fluxos de trabalho para converter fala em texto e texto em fala para interações agênticas': a Voice Live elimina a orquestração manual de STT, LLM e TTS em agentes de voz.

Dica de prova: Agente de voz em tempo real sem orquestrar componentes = Voice Live API.

Referência: Voice Live API
