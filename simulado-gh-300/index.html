Questão 1 de 12Aplicar engenharia de prompt e criação de contexto

Um desenvolvedor do Hotel Serra Azul quer uma função que devolva saudações conforme o horário do dia e coloca no prompt vários exemplos de entrada e saída, cobrindo manhã, tarde e noite. Que técnica ele está aplicando?

✓ Resposta: B) Few-shot prompting

Por quê: O Microsoft Learn descreve zero-shot (sem exemplos), one-shot (um exemplo para seguir o padrão) e few-shot (vários exemplos), este último equilibrando a imprevisibilidade do zero-shot e a precisão de um ajuste fino.

Dica de prova: Vários exemplos no prompt: few-shot.

Referência: Learn: fundamentos de engenharia de prompt

Questão 2 de 12Configurar privacidade, exclusões de conteúdo e proteções

Na Contábil Prime, que usa Copilot Business, um desenvolvedor ligou github.copilot.nextEditSuggestions.enabled no VS Code, mas não recebe next edit suggestions. O que pode estar faltando?

✓ Resposta: D) A política Editor preview features na organização

Por quê: Configurações do editor (como github.copilot.nextEditSuggestions.enabled) e políticas administrativas trabalham juntas: o usuário ativa no IDE, e a organização precisa permitir o recurso.

Dica de prova: Recurso do editor não aparece com licença da empresa: verifique a política.

Referência: Configurar o Copilot no IDE

Questão 3 de 12Entender a arquitetura e os dados do GitHub Copilot

Uma desenvolvedora da Rádio Norte percebe que o Copilot segue a instrução personalizada 'responda em português' na maioria das vezes, mas nem sempre. O que a documentação explica sobre isso?

✓ Resposta: C) A IA não é determinística e pode variar

Por quê: Modelos geram saídas de forma probabilística. Instruções curtas, claras e sem conflito entre níveis aumentam a consistência, mas não a garantem.

Dica de prova: Instrução nem sempre seguida: IA não determinística.

Referência: Instruções personalizadas do Copilot

Questão 4 de 12Melhorar a produtividade do desenvolvedor com o GitHub Copilot

Uma cientista de dados da Agro Análise quer ajuda para tratar valores ausentes, codificar variáveis categóricas e gerar gráficos com Matplotlib e Seaborn. Segundo o Microsoft Learn, como o Copilot apoia esse trabalho?

✓ Resposta: D) Sugere código de pré-processamento e de visualização

Por quê: Tratamento de valores ausentes, codificação de variáveis e escalonamento estão entre as tarefas de pré-processamento citadas pelo Learn.

Dica de prova: Ciência de dados: pré-processamento, estatística e gráficos.

Referência: Learn: preferências do desenvolvedor

Questão 5 de 12Usar o GitHub Copilot com responsabilidade

Uma estagiária da Corretora Aliança recebe do Copilot uma sugestão para uma função de criptografia que ela não entende bem. Segundo as boas práticas do GitHub, o que ela deve fazer antes de usar o código?

✓ Resposta: B) Pedir ao Copilot Chat que explique o código antes de decidir

Por quê: Para aceitar sugestões precisas e seguras: entenda o código antes de implementá-lo, revise com cuidado (funcionalidade, segurança, legibilidade e manutenção) e use testes e ferramentas automáticas.

Dica de prova: Não entendeu a sugestão? Peça ao Chat para explicar antes de usar.

Referência: Boas práticas para usar o Copilot

Questão 6 de 12Usar recursos do GitHub Copilot

No VS Code, um desenvolvedor da Loja Bambu não gostou da sugestão inline inicial e quer ver várias opções reunidas em uma nova aba para escolher a melhor. Qual atalho ele usa no Windows?

✓ Resposta: A) Ctrl+Enter

Por quê: Além de navegar pelas alternativas com Alt+] e Alt+[, o VS Code permite ver várias sugestões em uma aba separada com Ctrl+Enter.

Dica de prova: Várias sugestões em nova aba: Ctrl+Enter.

Questão 7 de 12Aplicar engenharia de prompt e criação de contexto

Em uma sessão longa do Copilot CLI, um desenvolvedor da Engenharia Vale quer ver quanto da janela de contexto já foi usada e manter o contexto principal focado enquanto faz pesquisas pesadas no código. O que a documentação indica?

✓ Resposta: B) Usar /context para ver o uso e delegar pesquisas a subagentes

Por quê: Se não for possível gerenciar bem o contexto, divida a conversa em sessões menores ou peça ao Copilot para truncar ou resumir saídas grandes de ferramentas.

Dica de prova: Medir contexto: /context; aliviar: subagentes.

Questão 8 de 12Configurar privacidade, exclusões de conteúdo e proteções

Uma referência de código mostra que uma sugestão aceita por um desenvolvedor da Software Brasa coincide com um repositório público sob licença GPL-3.0. Segundo a documentação, para que servem essas referências?

✓ Resposta: B) Para revisar origem e licença e decidir usar, atribuir ou remover

Por quê: Ao aceitar uma sugestão que corresponde a código público, o Copilot registra URLs dos arquivos e licenças detectadas. O índice cobre repositórios públicos do GitHub.com.

Dica de prova: Referência de código: avalie licença e origem antes de manter.

Referência: Copilot nos IDEs

Questão 9 de 12Entender a arquitetura e os dados do GitHub Copilot

No VS Code, além do texto digitado pela desenvolvedora, que contexto o Copilot Chat combina automaticamente ao prompt, segundo o application card?

✓ Resposta: D) Nome do repositório, arquivos abertos e o copilot-instructions.md, se houver

Por quê: Com o participante @github, o Chat no VS Code e no Visual Studio também pode buscar contexto do código no GitHub e da busca do Bing, se o administrador permitir.

Dica de prova: Contexto automático no IDE: repo, arquivos abertos e instruções.

Referência: Application card: Copilot Chat

Questão 10 de 12Melhorar a produtividade do desenvolvedor com o GitHub Copilot

Uma desenvolvedora da Saúde Mais precisa de uma estratégia de testes que abrange várias classes, novas fixtures e convenções do time ainda não documentadas. Segundo o Microsoft Learn, qual abordagem é a mais indicada?

✓ Resposta: C) Usar o Plan agent na estratégia e depois passar ao Agent

Por quê: O plano funciona como um contrato revisável antes do código. Para tarefas bem definidas, dá para ir direto ao Agent.

Dica de prova: Estratégia de testes complexa: Plan, depois Agent.

Referência: Learn: planejar e automatizar testes

Questão 11 de 12Usar o GitHub Copilot com responsabilidade

O time que desenvolve um assistente de IA para a Prefeitura Digital garante suporte a leitores de tela, legendas e controle por voz, além de funcionamento com conectividade limitada. Qual princípio de IA responsável é aplicado?

✓ Resposta: D) Inclusiveness (inclusão)

Por quê: O padrão de IA responsável da Microsoft pede que todos possam acessar os sistemas, independentemente de deficiência, idioma ou infraestrutura.

Dica de prova: Acessibilidade e alcance amplo: inclusiveness.

Referência: Learn: seis princípios de IA responsável

Questão 12 de 12Usar recursos do GitHub Copilot

Ao abrir o chat no VS Code atualizado, uma desenvolvedora da Software Coral vê as opções Ask e Plan no seletor, mas não encontra a opção Agent. O que a documentação indica sobre essa situação?

✓ Resposta: A) O administrador pode ter desabilitado o agent mode para o IDE
