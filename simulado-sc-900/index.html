Questão 1 · Conceitos de segurança, conformidade e identidade

Qual tipo de criptografia usa a mesma chave para cifrar e decifrar os dados?

  1. Hash de mão única
  2. Criptografia assimétrica
  3. Criptografia simétrica
  4. Assinatura digital
Ver resposta comentada

Resposta: C) Criptografia simétrica

Resposta correta: Criptografia simétrica

Por quê: A criptografia simétrica é rápida e usa uma chave compartilhada. A assimétrica usa chave pública para cifrar e privada para decifrar, e é base de assinaturas digitais.

Dica de prova: Mesma chave nos dois lados: simétrica.

Referência: Microsoft Learn: criptografia

Questão 9 · Conceitos de segurança, conformidade e identidade

Por que se adiciona um salt antes de gerar o hash de uma senha?

  1. Para permitir recuperar a senha original
  2. Para acelerar a comparação no login
  3. Para que senhas iguais tenham hashes distintos
  4. Para criptografar o tráfego da rede
Ver resposta comentada

Resposta: C) Para que senhas iguais tenham hashes distintos

Resposta correta: Para que senhas iguais tenham hashes distintos

Por quê: Sem salt, senhas iguais têm o mesmo hash, o que facilita ataques com tabelas pré-calculadas (rainbow tables).

Dica de prova: Salt: mesma senha, hash diferente.

Referência: Microsoft Learn: hash
