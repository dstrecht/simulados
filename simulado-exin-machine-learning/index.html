Questão 1 · Domínio 1: O que é aprendizado de máquina?

Segundo o guia, que combinação está no centro da aprendizagem profunda?

  1. Regras de especialistas e um mecanismo de inferência
  2. Poucos registros rotulados e cálculos feitos à mão
  3. Redes neurais combinadas a grandes conjuntos de dados
  4. Planilhas eletrônicas com fórmulas para cada registro
Ver resposta comentada

Resposta: C) Redes neurais combinadas a grandes conjuntos de dados

Resposta correta: Redes neurais combinadas a grandes conjuntos de dados

Por quê: A aprendizagem profunda, um subconjunto do aprendizado de máquina, treina grandes redes neurais profundas para processar e analisar grandes quantidades de dados, obter mais compreensão e resolver problemas mais complexos.

Dica de prova: Aprendizagem profunda = redes neurais grandes + muitos dados.

Referência: Guia de preparação EXIN AIMLA.PR (ed. 202506), item 1.4

Questão 3 · Domínio 3: Algoritmos usados no aprendizado de máquina

  1. Regressão logística
  2. Agrupamento K-means
  3. Agrupamento hierárquico
  4. Regressão polinomial
Ver resposta comentada

Resposta: A) Regressão logística

Resposta correta: Regressão logística

Por quê: A regressão logística aparece no guia entre os algoritmos de classificação. Ela devolve um valor entre 0 e 1, a probabilidade de o evento ocorrer, e permite ver como cada variável influencia o resultado.

Dica de prova: Apesar do nome 'regressão', a logística classifica: sim/não com probabilidade.

Questão 5 · Domínio 1: O que é aprendizado de máquina?

  1. Ela executa regras escritas uma a uma por um especialista
  2. Ela grava a fala para que uma pessoa a revise depois
  3. Ela determina o resultado a partir de padrões nos dados
  4. Ela converte a voz em uma tabela com colunas fixas
Ver resposta comentada

Resposta: C) Ela determina o resultado a partir de padrões nos dados

Resposta correta: Ela determina o resultado a partir de padrões nos dados

Por quê: O guia usa o reconhecimento de voz como exemplo: a entrada (voz capturada) é analisada e comparada com padrões armazenados para identificar o output, como uma ação específica ou a aceitação do comando de voz.

Dica de prova: No exemplo da voz, a rede neural faz entrada, comparação com padrões e resultado.

Questão 8 · Domínio 4: Aprendizado de máquina na prática

Em uma coluna de idade de um cadastro de clientes, parte dos registros está vazia. Que tratamento de limpeza é o mais adequado antes do treinamento?

  1. Preencher os vazios com um valor adequado, como a mediana
  2. Substituir os vazios por números sorteados ao acaso
  3. Preencher os vazios com o maior valor encontrado na coluna
  4. Manter os campos vazios e treinar o modelo assim mesmo
Ver resposta comentada

Resposta: A) Preencher os vazios com um valor adequado, como a mediana

Resposta correta: Preencher os vazios com um valor adequado, como a mediana

Por quê: A limpeza de dados faz parte da preparação descrita no item 4.2. Valores ausentes podem ser preenchidos (imputados) com uma estatística da própria coluna, como a média ou a mediana, em vez de descartar os registros.

Dica de prova: Valor ausente: trate na limpeza com um valor coerente, nunca invente nem ignore.

Referência: scikit-learn: Imputation of missing values

Questão 9 · Domínio 1: O que é aprendizado de máquina?

Sobre a relação entre IA e aprendizado de máquina, qual destas frases contraria o guia?

  1. A IA é um conceito recente, nascido com o aprendizado de máquina
  2. O aprendizado de máquina é usado na ciência de dados e com Big Data
  3. O aprendizado de máquina é um subconjunto da inteligência artificial
  4. O aprendizado de máquina é mais uma etapa na evolução da IA
Ver resposta comentada

Resposta: A) A IA é um conceito recente, nascido com o aprendizado de máquina

Resposta correta: A IA é um conceito recente, nascido com o aprendizado de máquina

Por quê: Segundo a orientação do item 1.1, a IA em si não é um conceito novo; o aprendizado de máquina é mais uma etapa na sua evolução e um subconjunto dela. Ele é usado na ciência de dados para obter compreensão de dados e Big Data.

Dica de prova: Quando a pergunta pede o que contraria o guia, procure a frase que inverte a ordem: a IA veio antes, e o aprendizado de máquina é uma etapa dela.

Referência: Guia de preparação EXIN AIMLA.PR (ed. 202506), item 1.1

Questão 11 · Domínio 3: Algoritmos usados no aprendizado de máquina

Os dados de consumo de energia em relação à temperatura formam uma curva, e não uma linha reta. Que algoritmo de regressão é mais adequado para modelar essa relação?

  1. Regressão logística
  2. Regressão polinomial
  3. Agrupamento K-means
  4. Regressão linear simples
Ver resposta comentada

Resposta: B) Regressão polinomial

Resposta correta: Regressão polinomial

Por quê: Regressão linear e regressão polinomial são os algoritmos de regressão citados no guia. Quando a relação entre as variáveis é curva, a regressão polinomial se ajusta melhor do que uma reta.

Dica de prova: Relação em linha reta = regressão linear; relação em curva = regressão polinomial.

Referência: scikit-learn: Polynomial regression (Linear Models)

Questão 12 · Domínio 4: Aprendizado de máquina na prática

Joana prepara dados de três fábricas para um modelo que prevê o consumo de matéria-prima. Uma fábrica registra o peso em quilos e outra em libras. A terceira grava as quantidades como texto, com a unidade escrita ao lado do número. O software escolhido exige uma única unidade e campos numéricos. Que tarefa de preparação resolve esse problema?

  1. Seleção de um novo algoritmo de regressão linear
  2. Revisão por pares dos resultados do teste
  3. Visualização dos dados em um painel
  4. Transformação dos dados para um padrão único
Ver resposta comentada

Resposta: D) Transformação dos dados para um padrão único

Resposta correta: Transformação dos dados para um padrão único

Por quê: O guia cita a transformação de dados para garantir que estejam em um formato adequado para uso no software escolhido. Converter libras em quilos e texto em número é transformação.

Dica de prova: Formato ou unidade incompatível com o software = transformação de dados.

Referência: Guia de preparação EXIN AIMLA.PR (ed. 202506), item 4.2
