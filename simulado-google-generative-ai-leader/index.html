Resumo por domínio e pegadinhas da Google Generative AI Leader

Como a prova pensa

A prova é para líderes, não para engenheiros: quase toda questão é um cenário de negócio curto que pede o produto, a técnica ou a prática mais adequada. Ela cobra os nomes vigentes dos produtos (Gemini Enterprise Agent Platform no lugar de Vertex AI, Agent Studio, Agent Search, Agent Runtime, Gemini Notebook, Gemini Enterprise for Customer Experience). Os distratores costumam ser serviços do Google Cloud sem relação com IA ou produtos de IA vizinhos com função parecida. Nos cenários de técnica, aumentar a temperatura é o distrator clássico; nas de estratégia, as erradas são extremas (proibir, aprovar tudo, desligar logs). A resposta certa é a que atende exatamente ao perfil do usuário e à necessidade descrita, com o menor esforço e com governança.

Fundamentos de IA Generativa (30% da prova)

  • Armadilha: Achar que todo modelo de fundação é um LLM. Como evitar: LLM é um modelo de fundação de linguagem; há modelos de fundação de imagem, áudio e outras modalidades.
  • Armadilha: Escolher ML é um tipo de IA generativa, que é parte da IA. Como evitar: A ordem correta é IA contém ML, que contém a IA generativa; não são sinônimos.
  • Gatilho: se o enunciado traz “dados já classificados / rotulados”, pense em: Aprendizado supervisionado.
  • Gatilho: se o enunciado traz “agrupar sem categorias definidas / transações incomuns sem rótulos”, pense em: Aprendizado não supervisionado (clusterização, detecção de anomalias).

Ofertas de IA Generativa do Google Cloud (35% da prova)

  • Armadilha: Indicar Google AI Studio com chave pessoal para empresa regulada levar a aplicação à produção. Como evitar: AI Studio é gratuito e para protótipo; produção com controles é Agent Studio na Agent Platform.
  • Armadilha: Escolher Gems personalizados ou Gemini Notebook para implantar uma aplicação. Como evitar: Gems personalizam o assistente do usuário e o Notebook é assistente de pesquisa; nenhum implanta aplicações.
  • Gatilho: se o enunciado traz “produção com IAM, rede, residência de dados e SLA”, pense em: Gemini Enterprise Agent Platform.
  • Gatilho: se o enunciado traz “catálogo com modelos do Google, de parceiros e abertos / implantar Gemma em endpoint”, pense em: Model Garden.

Técnicas para Melhorar a Saída dos Modelos (20% da prova)

  • Armadilha: Achar que temperatura zero garante fatos corretos ou que nunca alucina. Como evitar: Temperatura zero dá consistência, não precisão; grounding e avaliação continuam necessários.
  • Armadilha: Usar aumentar a temperatura como solução para qualidade, contexto irrelevante, fatos atuais ou bloqueios. Como evitar: Temperatura só controla variação; ela não traz conhecimento, não separa instruções e não trata filtros.
  • Gatilho: se o enunciado traz “sem nenhum exemplo”, pense em: Zero-shot.
  • Gatilho: se o enunciado traz “um único exemplo antes do pedido”, pense em: One-shot.

Estratégias de Negócio para Soluções de IA Generativa (15% da prova)

  • Armadilha: Marcar injeção de SQL, força bruta ou negação de serviço para dados de treino manipulados. Como evitar: Dados de treino manipulados é envenenamento de dados, risco específico de ML.
  • Armadilha: Tratar instruções escondidas em um documento recuperado como falha técnica comum. Como evitar: Conteúdo recuperado que manipula o modelo é injeção indireta de prompt.
  • Gatilho: se o enunciado traz “provocar respostas perigosas de propósito antes do lançamento”, pense em: Red teaming.
  • Gatilho: se o enunciado traz “instruções maliciosas para ignorar as regras”, pense em: Injeção de prompt; Model Armor.

Erros que mais custam pontos

  • Confundir Google AI Studio (protótipo grátis) com Agent Studio (produção na Agent Platform).
  • Trocar Agent Assist, Customer Experience Agent Studio e Customer Experience Insights.
  • Responder com nomes antigos ou achar que a Agent Platform só tem modelos do Google.
  • Acreditar que temperatura zero elimina alucinação ou usar ajuste fino para dados que mudam.
