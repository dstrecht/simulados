Questão 1 · Aumentar a produtividade usando o GitHub Copilot

  1. Trocar para outro modelo e manter o lembrete do jeito que está
  2. Anexar uma planilha vazia para o Copilot deduzir o formato certo
  3. Repetir o lembrete três vezes ao longo do prompt para reforçar
  4. Declarar a regra diretamente: Devolva o resultado em uma tabela

Resposta: D) Declarar a regra diretamente: Devolva o resultado em uma tabela

Resposta correta: Declarar a regra diretamente: Devolva o resultado em uma tabela

  2. O rewind exige que a sessão esteja no modo Plan
  3. O rewind só vale para sessões com nome definido
  4. O rewind só aparece depois de 24 horas da sessão

Questão 6 · Projetar e implementar fluxos de trabalho e automações agênticos

A gerente de segurança da Fintech Ipê pergunta o que acontece com as saídas propostas por um agentic workflow antes de qualquer escrita no repositório. O que a documentação descreve?

  1. São gravadas na wiki e só depois aplicadas no repositório pelo agente
  2. São enviadas por e-mail para a equipe de segurança aprovar uma a uma
  3. Vão direto para o branch padrão, sem nenhuma verificação extra
  4. Passam por detecção de ameaças que procura mudanças suspeitas
Ver resposta comentada

Resposta: D) Passam por detecção de ameaças que procura mudanças suspeitas

Resposta correta: Passam por detecção de ameaças que procura mudanças suspeitas

Por quê: Guardrails dos agentic workflows: somente leitura por padrão, escritas só via safe outputs, secrets fora do runtime do agente, detecção de ameaças nas saídas, execução com firewall e controle de quem pode disparar ou alterar.

Dica de prova: Antes de escrever: detecção de ameaças.

Questão 8 · Usar os recursos da plataforma GitHub

  2. O uso é bloqueado, porque o orçamento por usuário é uma parada rígida
  3. O uso gera alerta para o administrador, mas não é interrompido por isso
  4. O uso continua até o pool de créditos da empresa acabar e só então para
Ver resposta comentada

Resposta: B) O uso é bloqueado, porque o orçamento por usuário é uma parada rígida

Resposta correta: O uso é bloqueado, porque o orçamento por usuário é uma parada rígida
