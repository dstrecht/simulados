Questão 1 de 12105 Shells e Scripts

Qual variável define o formato do prompt principal do bash?

✓ Resposta: C) PS1

Por quê: PS1 aceita sequências como \u (usuário), \h (máquina) e \w (diretório).

Dica de prova: Prompt: PS1.

Referência: LPIC-1 Objectives V5.0, objetivo 105.1 (Ambiente do shell)

Questão 2 de 12106 Interfaces de Usuário e Desktops

Por que o comando xhost + é considerado inseguro?

✓ Resposta: D) Libera o servidor X a qualquer máquina

Por quê: O controle por xauth ou encaminhamento X pelo SSH é mais seguro.

Dica de prova: xhost +: libera geral.

Referência: LPIC-1 Objectives V5.0, objetivo 106.1 (X11)

Questão 3 de 12107 Tarefas Administrativas

Qual comando adiciona o usuário ana ao grupo docker sem removê-la dos outros grupos secundários?

✓ Resposta: C) usermod -aG docker ana

Por quê: -a com -G acrescenta; só -G substitui os grupos secundários.

Dica de prova: Acrescentar a grupo: usermod -aG.

Referência: LPIC-1 Objectives V5.0, objetivo 107.1 (Usuários e grupos)

Questão 4 de 12108 Serviços Essenciais do Sistema

Qual comando envia relatorio.pdf para a impressora chamada financeiro?

✓ Resposta: A) lpr -P financeiro relatorio.pdf

Por quê: lpr -P escolhe a impressora; sem -P, usa a padrão.

Dica de prova: Imprimir em fila específica: lpr -P.

Referência: LPIC-1 Objectives V5.0, objetivo 108.4 (Impressão)

Questão 5 de 12109 Fundamentos de Rede

Qual comando mostra o estado de cada dispositivo de rede gerenciado pelo NetworkManager?

✓ Resposta: A) nmcli device status

Por quê: nmcli device (dev) mostra interfaces, tipos e conexões ativas.

Dica de prova: Dispositivos no nmcli: nmcli device status.

Referência: LPIC-1 Objectives V5.0, objetivo 109.2 (Configuração de rede)

Dica de prova: sudo: rastreabilidade e controle.
