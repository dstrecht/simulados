Questão 1 de 12Implementar e gerenciar modelos semânticos

No grupo de cálculo Moeda da Exportadora Café Bravo, o item Em Dólar multiplica a medida selecionada pela cotação, mas não deve alterar as medidas [Quantidade Sacas] e [Pedidos], que não são valores monetários. Como escrever a expressão do item?

✓ Resposta: D) IF(ISSELECTEDMEASURE([Quantidade Sacas], [Pedidos]), SELECTEDMEASURE(), SELECTEDMEASURE() * [Cotacao])

Por quê: Em itens de cálculo, SELECTEDMEASURE representa a medida em avaliação, SELECTEDMEASURENAME devolve seu nome e ISSELECTEDMEASURE testa se ela está em uma lista. Isso permite aplicar o item só a certas medidas.

Dica de prova: Item de cálculo que deve pular algumas medidas: ISSELECTEDMEASURE.

Referência: Função ISSELECTEDMEASURE (DAX)

Questão 2 de 12Manter uma solução de análise de dados

Um DBA da Empresa de Logística Norte Cargas quer conectar o SQL Server Management Studio a um workspace do Fabric para executar scripts TMSL nos modelos semânticos. O XMLA read-write já foi habilitado na capacidade. Onde ele obtém o endereço que deve informar como nome do servidor?

✓ Resposta: B) Nas configurações do workspace, em Workspace Connection, copiando o endereço powerbi://

Por quê: Workspaces em capacidade têm uma URL de conexão XMLA usada como se fosse o nome de um servidor do Analysis Services. No SSMS, escolha o tipo Analysis Services, informe essa URL e autentique com Microsoft Entra (MFA); cada modelo semântico aparece como um banco.

Dica de prova: SSMS no Power BI/Fabric: servidor = URL powerbi:// do Workspace Connection.

Referência: Conectividade de modelos semânticos com o ponto de extremidade XMLA

Questão 3 de 12Preparar dados

No warehouse da Companhia Aérea Céu Limpo, a coluna ValorTexto de uma tabela de staging tem valores como 123.45, N/D e textos vazios. O analista precisa convertê-la para decimal em uma consulta sem que as linhas inválidas façam a consulta falhar. Qual expressão ele deve usar?

✓ Resposta: C) TRY_CAST(ValorTexto AS DECIMAL(10,2))

Por quê: TRY_CAST e TRY_CONVERT, suportados no warehouse e no SQL analytics endpoint, tentam a conversão e devolvem NULL quando ela falha. São úteis em dados de staging com valores sujos; os nulos resultantes podem ser tratados depois com ISNULL ou COALESCE.

Dica de prova: Converter sem quebrar a consulta: TRY_CAST.

Referência: TRY_CAST (Transact-SQL)

Questão 4 de 12Implementar e gerenciar modelos semânticos

A gerente da Rede de Supermercados Feira Livre quer que os usuários escolham, em um slicer, se um gráfico de barras mostra as vendas por Região, por Loja ou por Categoria. O que o modelador deve criar?

✓ Resposta: D) Um field parameter, em Modeling, New parameter, Fields, com as três colunas

Por quê: Field parameters permitem que o leitor troque dinamicamente as medidas ou dimensões analisadas em um relatório. A expressão DAX gerada lista nome, NAMEOF da coluna e ordem; também é possível editar a tabela para incluir novos campos.

Dica de prova: Trocar a dimensão do gráfico por slicer: field parameter.

Referência: Parâmetros de campo (field parameters)

Questão 5 de 12Manter uma solução de análise de dados

Um desenvolvedor da Startup Dados Vivos abre no Power BI Desktop o arquivo Vendas.pbix e usa File, Save as para salvá-lo como Power BI Project (.pbip) em uma pasta vazia. Que estrutura ele encontra na pasta?

✓ Resposta: A) Pastas Vendas.Report e Vendas.SemanticModel em texto, um .gitignore e o arquivo Vendas.pbip

Por quê: Salvar como PBIP gera as pastas nome.Report e nome.SemanticModel, com definições em texto adequadas a Git, diff e CI/CD. O .gitignore padrão exclui localSettings.json e cache.abf; o .pbip é opcional, pois o definition.pbir também abre o projeto.

Dica de prova: PBIP: pastas .Report e .SemanticModel, .gitignore e .pbip.

Referência: Projetos do Power BI Desktop (PBIP)

Questão 6 de 12Preparar dados

Um Dataflow Gen2 da Exportadora Brasil Frutas lê um CSV de um parceiro dos Estados Unidos, com datas no formato 10/22/2026 e números como 1,234.56. Ao mudar os tipos das colunas no Power Query, que usa outra configuração regional, várias linhas dão erro. O que fazer?

✓ Resposta: D) Usar Change type Using locale com English (United States)

Por quê: A localidade (locale) controla como textos são interpretados ao converter para data ou número. Quando a origem usa formato diferente do projeto, a conversão com Using locale por coluna resolve sem mudar a localidade de toda a consulta.

Dica de prova: Data ou número em formato estrangeiro: Change type Using locale.

Referência: Tipos de dados no Power Query

Questão 7 de 12Implementar e gerenciar modelos semânticos

A equipe de BI da Mineradora Terra Firme desenvolve um modelo Direct Lake on SQL sobre um warehouse corporativo. Em produção, o modelo deve continuar respondendo mesmo que alguma condição do Direct Lake deixe de ser atendida, ainda que fique mais lento. Durante o desenvolvimento, porém, os engenheiros querem descobrir na hora qualquer consulta que cairia para DirectQuery, para corrigir a causa, e também querem medir o desempenho do modelo como se todas as consultas rodassem em DirectQuery. O modelo é publicado por um deployment pipeline. Quais valores da propriedade Direct Lake behavior usar em cada situação?

✓ Resposta: D) Automatic em produção; DirectLakeOnly para achar falhas e DirectQueryOnly para medir

Por quê: A propriedade DirectLakeBehavior vale para Direct Lake on SQL e é ajustada no painel Properties do modelo ou por TOM e TMSL. Para entender as causas de fallback, use EVALUATE TABLETRAITS().

Dica de prova: Produção Automatic; depurar com DirectLakeOnly; medir com DirectQueryOnly.

Referência: Como o Direct Lake funciona

Questão 8 de 12Manter uma solução de análise de dados

Um administrador de dados da Rede de Escolas Aprender Mais vai migrar o servidor SQL que alimenta vários modelos semânticos e abre a impact analysis a partir do card da fonte de dados, na lineage view, para avaliar o efeito da mudança até os relatórios. O que essa análise mostra para uma fonte de dados?

✓ Resposta: B) Os filhos diretos da fonte e a cadeia de conexão; para ir além, analisar cada filho

Por quê: A impact analysis mostra os itens e workspaces potencialmente afetados por uma mudança, com abas de filhos diretos e de todos os itens downstream, agrupamento por tipo ou workspace e o botão Notify contacts. Para fontes de dados, mostra só filhos diretos e a cadeia de conexão.

Dica de prova: Impact analysis de fonte de dados: um nível só; siga pelos filhos.

Referência: Impact analysis no Fabric

Questão 9 de 12Preparar dados

A Rede de Lojas Tem de Tudo quer usar a OneLake integration de um modelo semântico Import para que cientistas de dados leiam as tabelas em notebooks. O workspace do modelo está em Premium Per User. O que acontece?

✓ Resposta: C) Não é suportado em PPU; o modelo precisa estar em capacidade Premium P ou Fabric F

Por quê: Com a OneLake integration ligada nas configurações do modelo (e as configurações de locatário permitindo), as tabelas Import são gravadas em Delta após um refresh. O recurso exige capacidade P ou F.

Dica de prova: OneLake integration de modelo semântico: só em capacidade P ou F.

Referência: OneLake integration para modelos semânticos

Questão 10 de 12Implementar e gerenciar modelos semânticos

A Fintech Rumo Certo tem dois modelos semânticos Direct Lake com SSO sobre o mesmo lakehouse, que não tem a OneLake security habilitada: Riscos, em Direct Lake on SQL, e Crédito, em Direct Lake on OneLake. Analistas de outra diretoria, que não têm papel no workspace, precisam abrir relatórios dos dois modelos. Eles já receberam Read nos relatórios e nos modelos semânticos. O time de segurança quer conceder o mínimo necessário no lakehouse para cada caso e pediu ao engenheiro de dados uma lista objetiva antes de liberar o acesso. Que permissões no lakehouse cada modelo exige desses usuários?

✓ Resposta: A) Riscos: Read no item e SELECT nas tabelas; Crédito: Read e ReadAll no lakehouse

Por quê: Com SSO, o Direct Lake confere as permissões de quem consulta. Em Direct Lake on SQL, bastam Read no item e SELECT nas tabelas pelo SQL analytics endpoint; em Direct Lake on OneLake, Read e ReadAll no item (ou uma função da OneLake security). Para dispensar permissões dos usuários, use conexão de nuvem com identidade fixa.

Dica de prova: On SQL pede SELECT pelo endpoint; on OneLake pede ReadAll ou OneLake security.

Referência: Integrar a segurança do Direct Lake

Questão 11 de 12Manter uma solução de análise de dados

A gerente da Imobiliária Casa Certa quer enviar a um colega o link de um relatório que ele já tem permissão para ver, sem conceder nenhum acesso novo. Qual tipo de link do diálogo de compartilhamento ela deve escolher?

✓ Resposta: D) People with existing access, que gera o link sem conceder acesso

Por quê: O diálogo de compartilhamento oferece links para People in your organization, People with existing access e Specific people. Os dois primeiros e o último concedem acesso, exceto People with existing access, que só gera a URL. O admin pode desativar o primeiro tipo no locatário.

Dica de prova: Só mandar o link para quem já acessa: People with existing access.

Referência: Compartilhar itens no Microsoft Fabric

Questão 12 de 12Preparar dados

A Companhia de Saneamento Gota Limpa ligou a OneLake availability em um banco KQL cuja política de retenção é de 90 dias e criou atalhos no lakehouse para uso em notebooks. Um cientista de dados espera encontrar no Delta dois anos de histórico. O que acontece com os dados mais antigos que 90 dias?

✓ Resposta: C) São removidos do OneLake também, pois a retenção do banco KQL vale para a cópia em Delta

Por quê: Com OneLake availability, a cópia lógica em Delta acompanha o banco KQL, inclusive a política de retenção. Para histórico maior no lake, é preciso aumentar a retenção no banco ou gravar os dados em outro destino.

Dica de prova: Retenção do banco KQL também apaga a cópia Delta no OneLake.

Referência: OneLake availability em um Eventhouse
