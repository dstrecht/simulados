Questão 1 de 12 · Configuração do Terraform

Qual tipo de variável é adequado para receber um conjunto de atributos com nomes e tipos definidos, como um nome em texto e uma lista de portas numéricas?

Resposta: D) Tipo object

Por quê: Já map exige que todos os valores tenham o mesmo tipo.

Dica de prova: Atributos nomeados com tipos diferentes: object.

Referência: Terraform Associate 004 Exam Content List, objetivo 4d

Questão 2 de 12 · Fluxo de Trabalho Principal

Verdadeiro ou falso: terraform validate precisa de um diretório já inicializado com terraform init.

Resposta: A) Verdadeiro

Por quê: Em CI, é comum rodar terraform init -backend=false antes do validate.

Dica de prova: validate precisa de init.

Referência: Terraform Associate 004 Exam Content List, objetivo 3c

Questão 3 de 12 · Fundamentos do Terraform

Qual é a divisão de responsabilidades entre o Terraform Core e os providers?

Resposta: A) O Core monta o plano; o provider chama as APIs

Por quê: O Core lê a configuração e o estado e calcula o grafo; os providers implementam os recursos.

Dica de prova: Core: grafo e plano; provider: APIs.

Referência: Terraform Associate 004 Exam Content List, objetivo 2b

Questão 4 de 12 · Gerenciamento de State

Uma execução foi interrompida e o estado ficou bloqueado. Qual comando libera o bloqueio, com cuidado?

Resposta: D) terraform force-unlock ID_DO_LOCK

Por quê: Só use se tiver certeza de que nenhuma outra operação está em andamento.

Dica de prova: Lock preso: force-unlock.

Referência: Terraform Associate 004 Exam Content List, objetivo 6b

Questão 5 de 12 · HCP Terraform

Qual fluxo do HCP Terraform é mais indicado quando outra ferramenta de automação precisa enviar configurações e disparar runs?

Resposta: B) Fluxo orientado por API

Por quê: A API permite enviar versões de configuração e criar runs.

Dica de prova: Automação externa: fluxo por API.

Referência: Terraform Associate 004 Exam Content List, objetivo 8d

Questão 6 de 12 · Infraestrutura como Código com Terraform

Os ambientes de homologação e produção devem ser o mais parecidos possível. Como a IaC contribui para isso?

Resposta: A) Os dois usam o mesmo código com variáveis

Por quê: Variáveis e tfvars por ambiente controlam o que realmente precisa mudar, como tamanho de máquinas.

Dica de prova: Paridade de ambientes: mesmo código.

Questão 7 de 12 · Manutenção da Infraestrutura

Um recurso foi renomeado no código de aws_instance.app para aws_instance.api. Como evitar que o Terraform o destrua e recrie?

Resposta: D) Bloco moved de app para api
