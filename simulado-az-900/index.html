Questão 1 de 12Descrever a arquitetura e os serviços do Azure

Duas VMs estão em sub-redes diferentes da mesma rede virtual, sem NSG aplicado. O que é preciso para que elas se comuniquem?

✓ Resposta: B) Nenhuma ação, pois sub-redes da mesma rede já se comunicam

Por quê: Dentro de uma rede virtual, as rotas do sistema permitem a comunicação entre sub-redes. Para restringir esse tráfego, usam-se grupos de segurança de rede.

Dica de prova: Mesma rede virtual: sub-redes já se falam.

Referência: O que é a Rede Virtual do Azure

Questão 2 de 12Descrever conceitos de nuvem

Qual serviço do Azure é um exemplo de plataforma como serviço (PaaS)?

✓ Resposta: C) Banco de Dados SQL do Azure

Por quê: Serviços PaaS entregam uma plataforma gerenciada para desenvolver ou hospedar aplicações e dados, como o Banco de Dados SQL do Azure e o Serviço de Aplicativos.

Dica de prova: Banco gerenciado sem cuidar do SO: PaaS.

Referência: Microsoft Learn: tipos de serviço de nuvem

Questão 3 de 12Descrever o gerenciamento e a governança do Azure

Uma política foi atribuída a uma assinatura, mas um grupo de recursos de laboratório deve ficar fora dela. Como fazer isso sem remover a atribuição?

✓ Resposta: C) Configurar uma exclusão desse grupo na atribuição

Por quê: Ao atribuir uma política, é possível definir exclusões de escopos filhos. Também existem isenções, que registram exceções com justificativa e prazo.

Dica de prova: Deixar um grupo fora da política: exclusão na atribuição.

Referência: Estrutura de atribuição do Azure Policy

Questão 4 de 12Descrever a arquitetura e os serviços do Azure

Os administradores precisam acessar VMs por RDP e SSH pelo portal do Azure, sem expor as VMs com endereço IP público. Qual serviço atende a esse requisito?

✓ Resposta: D) Azure Bastion

Por quê: O Azure Bastion é um serviço PaaS implantado na rede virtual que permite RDP e SSH pelo navegador, via TLS, sem expor as VMs à internet.

Dica de prova: RDP/SSH pelo portal sem IP público: Bastion.

Referência: O que é o Azure Bastion

Questão 5 de 12Descrever conceitos de nuvem

Por exigência regulatória, uma empresa precisa manter certos dados no próprio datacenter, mas quer usar a nuvem para as demais cargas. Qual modelo de nuvem atende a esse cenário?

✓ Resposta: C) Nuvem híbrida

Por quê: A nuvem híbrida é comum quando parte dos dados ou sistemas precisa continuar no ambiente local por exigências legais ou técnicas.

Dica de prova: Parte local por regra, parte na nuvem: híbrida.

Referência: Microsoft Learn: nuvem híbrida

Por quê: Iniciativas do Azure Policy simplificam a governança ao agrupar políticas relacionadas a um mesmo objetivo.

Dica de prova: Várias políticas juntas: iniciativa.

Como uma empresa estabelece uma conexão do ExpressRoute entre o datacenter e o Azure?

✓ Resposta: D) Por meio de um provedor de conectividade parceiro

Questão 8 de 12Descrever conceitos de nuvem

Uma aplicação está lenta e a equipe troca a VM por outra com mais CPU e memória. Que tipo de escalabilidade é essa?

✓ Resposta: A) Escalabilidade vertical

Por quê: Escalar verticalmente é aumentar ou reduzir a capacidade de um recurso. Escalar horizontalmente é mudar o número de instâncias.

Dica de prova: Máquina maior: vertical. Mais máquinas: horizontal.

Referência: Microsoft Learn: escalabilidade

Questão 9 de 12Descrever o gerenciamento e a governança do Azure

Uma empresa precisa impedir que recursos sejam criados fora das regiões Brazil South e East US em todas as assinaturas. Qual serviço aplica essa regra?

✓ Resposta: A) Azure Policy

Por quê: O Azure Policy ajuda a impor padrões e avaliar a conformidade em escala, inclusive com iniciativas que agrupam várias políticas.

Dica de prova: Impor regras de criação de recursos: Azure Policy.

Referência: Azure Policy

Questão 10 de 12Descrever a arquitetura e os serviços do Azure

Qual afirmação diferencia um grupo de segurança de rede (NSG) do Firewall do Azure?

✓ Resposta: B) O NSG usa regras básicas; o Firewall é um serviço gerenciado central

Por quê: O NSG filtra tráfego com regras de permissão e negação. O Firewall do Azure adiciona recursos avançados e é usado para proteger várias redes de forma centralizada.

Dica de prova: NSG: regras simples. Firewall: serviço central e avançado.

Referência: O que é o Firewall do Azure

Questão 11 de 12Descrever conceitos de nuvem

No datacenter local, por que as empresas costumam comprar mais capacidade de servidor do que usam na maior parte do tempo?

✓ Resposta: D) Para suportar os picos de demanda previstos

Por quê: No ambiente local, a capacidade é comprada para o pico, gerando ociosidade. Na nuvem, a elasticidade ajusta os recursos à demanda e evita esse desperdício.

Dica de prova: Local compra para o pico; nuvem acompanha a demanda.

Referência: Microsoft Learn: benefícios da nuvem

Questão 12 de 12Descrever o gerenciamento e a governança do Azure

Onde a equipe de governança vê o percentual de recursos em conformidade com as políticas atribuídas?

✓ Resposta: C) No painel de conformidade do Azure Policy

Por quê: O Azure Policy avalia os recursos continuamente e apresenta um painel de conformidade para acompanhar e corrigir desvios.

Dica de prova: Conformidade das políticas: painel do Azure Policy.

Referência: Azure Policy: dados de conformidade
